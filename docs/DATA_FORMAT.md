# データ仕様（形式version 1）

実装の正本は `packages/core/config.js`（本体データの検証）、`packages/core/view-state.js`（表示データ）、`packages/core/graph.js`（座標・線の計算）です。Schemaは `schema/` にあります。アプリ版0.1.0とデータ形式の `version: 1` は別です。

## 本体ファイル

UTF-8のJSONまたはJSONC。JSONCの `//`、`/* ... */` コメントと末尾カンマ、UTF-8 BOMに対応します。最上位はオブジェクトです。同じオブジェクト内の重複キー、未知の項目はエラーです。最大2,097,152文字（JavaScript文字列のUTF-16コード単位）。

| 項目 | 型・必須 | 内容・省略時 |
| --- | --- | --- |
| `$schema` | 文字列・任意 | Schemaの場所。2,000文字以内。拡張の描画処理はこれをネット取得しない |
| `version` | 数値・任意 | 指定時は `1` |
| `title` | 文字列・任意 | 200文字以内。未指定・空なら表示は「相関図」 |
| `description` | 文字列・任意 | 4,000文字以内。詳細・その他メニューで表示 |
| `layout` | 文字列・任意 | `auto`（初期値）/ `circle` |
| `groups` | 配列・任意 | 最大50グループ。省略時は空 |
| `nodes` | 配列・必須 | 最大200人物・項目。空配列可 |
| `edges` | 配列・必須 | 最大1,000関係。空配列可 |

文字数上限は以下もUTF-16コード単位です。ID・必須の名前は空白だけでは指定できません。IDは日本語も使え、大文字小文字を区別します。IDと表示名を分けて管理してください。

## グループ：全体の `groups[]`

| 項目 | 型・必須 | 内容 |
| --- | --- | --- |
| `id` | 文字列・必須 | グループ内で一意。100文字以内 |
| `label` | 文字列・必須 | 表示名。200文字以内 |
| `color` | 文字列・任意 | `#abc` または `#55b8ad`。省略時は定義順に自動配色 |

## キャラクター：`nodes[]`

| 項目 | 型・必須 | 内容 |
| --- | --- | --- |
| `id` | 文字列・必須 | 人物内で一意。100文字以内 |
| `label` | 文字列・必須 | 表示名。200文字以内 |
| `groups` | 文字列配列・任意 | 定義済みグループID。最大50、重複不可。空配列可 |
| `group` | 文字列・任意 | 旧形式の単一所属。100文字以内。`groups` と併記不可 |
| `description` | 文字列・任意 | 詳細。4,000文字以内 |
| `color` | 文字列・任意 | 人物枠の色。所属色より優先 |
| `x`, `y` | 数値・任意 | 両方指定。各-20,000～20,000の有限数 |

座標は図の内部座標で、右がX正・下がY正です。未指定は自動／円形配置。ドラッグ位置は本体ではなく表示ファイルに保存します。固定座標を変更すると、以前のドラッグ位置より新しい固定座標が優先されます。

```jsonc
{
  "groups": [
    { "id": "party", "label": "旅の仲間", "color": "#55b8ad" },
    { "id": "guild", "label": "探索隊", "color": "#78aee8" }
  ],
  "nodes": [
    { "id": "hero", "label": "主人公", "groups": ["party", "guild"] },
    { "id": "friend", "label": "親友", "groups": ["party"] }
  ],
  "edges": []
}
```

人物枠は `color` → 最初の所属グループ色 → 既定色の順です。左側の色帯には各所属色を表示します。所属順序は表示に影響します。GUIで人物を保存すると旧 `group` は `groups` に変わります。

## 関係：`edges[]`

| 項目 | 型・必須 | 内容・省略時 |
| --- | --- | --- |
| `from`, `to` | 文字列・必須 | 定義済み人物ID。各100文字以内 |
| `label` | 文字列・任意 | 線の表示名。200文字以内。省略時は空 |
| `description` | 文字列・任意 | 4,000文字以内 |
| `color` | 文字列・任意 | 線と矢印の色。省略時はテーマの線色 |
| `arrow` | 文字列・任意 | `forward`（from→to、初期値）/ `both` / `none` |
| `style` | 文字列・任意 | `solid`（初期値）/ `dashed` / `dotted` |
| `shape` | 文字列・任意 | `auto`（初期値）/ `straight` / `curved` |
| `setId` | 文字列・任意 | 並行線セット。空白だけでない100文字以内 |

色は全項目共通で3桁／6桁の16進表記のみ。色名・透明度付き8桁表記は未対応です。

- 同じ二人を結ぶ複数の線、逆向きの線を定義できます。関係そのものの `id` 項目はありません。編集時は配列の位置で識別します。
- `setId` は同じ二人の間だけで共有します。逆向きでも同じセットにできます。別の二人には別のIDを使います。
- 同じセットの明示した `shape` は統一します。一部だけ `straight` または `curved` を指定した場合、他の `auto`／省略の線もその形を引き継ぎます。
- `straight` は他の人物を迂回しません。`auto`／`curved` の迂回も完全な重なり回避を保証しません。
- 自分自身を結ぶ線に `setId` は使えません。形は `auto`／`curved` にします。
- 線の並びは `edges` の順序に基づきます。GUIからセットの形を変更すると、同じセットの明示指定も追従します。

次の配列は上の例の `edges` を置き換えて使えます。

```json
[
  { "from": "hero", "to": "friend", "label": "信頼", "setId": "pair", "shape": "straight" },
  { "from": "friend", "to": "hero", "label": "憧れ", "setId": "pair", "style": "dashed", "color": "#e797b0" }
]
```

## 表示ファイル：`元ファイル名.view.json`

例：`cast.jsonc` → `cast.jsonc.view.json`、`cast.relations.json` → `cast.relations.json.view.json`。
通常のJSONのみ（コメント・末尾カンマ不可）、UTF-8 BOM可、最大200,000文字。最小値は `{"version":1}` です。通常はアプリに生成させてください。

| 項目 | 型・必須 | 内容 |
| --- | --- | --- |
| `version` | 数値・必須 | `1` |
| `layout` | 文字列・任意 | 画面で選んだ `auto`／`circle` |
| `configLayout` | 文字列・任意 | 保存時の本体 `layout`。設定変更を判定する記録 |
| `positions` | オブジェクト・任意 | 人物ID→位置。最大200件。省略時は空 |
| `positions[id].x`, `.y` | 数値・必須 | 各-20,000～20,000 |
| `positions[id].source` | 文字列・必須 | 固定座標の署名。100文字以内。下記参照 |
| `camera` | オブジェクト・任意 | 表示位置と倍率 |
| `camera.x`, `.y` | 数値・必須 | 画面上の平行移動量。各-1,000,000～1,000,000 |
| `camera.scale` | 数値・必須 | 倍率。0.01～4 |
| `camera.width`, `.height` | 数値・任意 | 保存時の描画領域サイズ。両方指定、0より大きく100,000以下 |
| `ui.details` | 真偽値・任意 | 詳細欄を開くか |
| `ui.focus` | 真偽値・任意 | 図だけ表示にするか |

未知の項目はエラーです。人物IDのキーは空白だけでない100文字以内。位置・カメラの数値は有限数です。`ui` は省略できます。

`source` はファイルパスではなく、本体の固定座標を `x,y` にした文字列です。固定座標がなければ `","`、`x:100, y:200` なら `"100,200"`。一致するドラッグ位置だけ再利用します。

```json
{
  "version": 1,
  "layout": "auto",
  "configLayout": "auto",
  "positions": {
    "hero": { "x": -200, "y": 0, "source": "," }
  },
  "camera": { "x": 640, "y": 380, "scale": 1, "width": 1280, "height": 760 },
  "ui": { "details": false, "focus": false }
}
```

表示座標の概念は `画面座標 = 図の内部座標 × scale + cameraの移動量` です。画面サイズが変わる場合は中心を維持するよう補正します。検索語・選択中の人物・元ファイルの絶対パスは保存しません。

本体の `layout` を変更すると表示側の配置方式も切り替わります。表示側だけで配置方式を変えた場合、本体は変更しません。人物ID変更時の位置の追従はGUI経由で行います。テキストでIDを変えた場合は対応する表示位置も必要に応じて調整します。

## SchemaとAIへの依頼

`*.relations.jsonc`／`*.relations.json` は拡張のSchema関連付けが有効です。任意名で補完も使う場合は、たとえばリポジトリの `examples/登場人物.jsonc` に `"$schema": "../schema/relations.schema.json"` を書けます。この相対パスはその配置専用なので、別フォルダへコピーする場合はSchemaも配置し直すか関連付けを変更してください。

Schemaは型や選択肢を検証します。IDの一意性・参照先の存在・セット内の整合性は `parseConfig()` でも検証します。Schemaだけの成功では十分ではありません。

AIにはこの仕様、サンプル、追加したい人物・関係を渡し、「既存IDを維持する」「未対応の項目を作らない」「groupsの参照先を定義する」「同じsetIdの形を統一する」を指定してください。生成後は相関図を開いてエラーを確認します。表示ファイルは、配置も指定したい場合にだけ生成します。
