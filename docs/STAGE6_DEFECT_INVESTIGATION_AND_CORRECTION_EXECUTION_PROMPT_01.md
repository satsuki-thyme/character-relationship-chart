## 調査・修正対象

### 1. 表示データ保存後に画面状態が正しく復元されない

実機確認で、表示データ保存前の画面と、保存した表示データを開き直した後の画面が異なる現象が確認されています。

比較画像:

- `docs/images/stage6-phisycal-device-check5-1.png`
- `docs/images/stage6-phisycal-device-check5-2.png`

第6段階の完了条件は、設定ファイルと `<本体ファイル名>.view.json` を組として保存・再読込した際に、人物配置・倍率・表示状態等が復元されることです。

次を切り分けてください。

- 保存されている表示データそのものが不足しているか
- 保存時点の内部状態と生成される `.view.json` が一致しているか
- 読込時に保存済み座標が正しくcore/UIへ渡されているか
- 読込後に自動配置等が再実行され、保存済み座標を上書きしていないか
- 倍率、カメラ位置、配置方式、詳細欄等の状態のどれが失われているか
- 固定座標と自動配置の優先順位に問題がないか
- 設定ファイルと表示データの対応付けに問題がないか

見た目だけで原因を決めず、保存された `.view.json` の実内容、読込後の内部状態、描画結果を照合してください。

### 2. 人物を連続してドラッグするとキャンバスドラッグになる

実機では次の現象があります。

- 人物を一人ドラッグする。
- 続けて別の人物をドラッグしようとすると、人物ではなく背景をつかんだように図全体が移動する。
- 一度背景をクリックしてから人物をドラッグすると正常に戻る。
- 正常化後は続けてドラッグできる。
- 別ページを表示して戻ってくると再発する。

次を調べてください。

- pointer / mouse / drag の開始・終了状態が残留していないか
- node drag と canvas pan の状態が排他的に解除されているか
- pointer capture の取得・解放に不整合がないか
- `pointerup` / `pointercancel` / `lostpointercapture` 等の処理漏れがないか
- ページ切替・再表示時のUI状態初期化に不足がないか
- Web版固有ではなく共有UIやVS Code版にも影響する問題か

修正は既存設計と共有UIの責務を尊重し、場当たり的なタイマーや強制クリック等ではなく、ドラッグ状態の正しいライフサイクルを直してください。
