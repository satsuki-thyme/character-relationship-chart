# スクリーンショット

現行版の実機スクリーンショットはまだありません。

1. VSIXをデスクトップ版VS Codeへインストールします。
2. 公開用サンプルを別の作業フォルダへコピーし、「相関図を表示」で開きます。
3. 「全体」で図を収め、`preview.png` としてこのフォルダへ保存します。
4. 「編集」→「キャラクター」で複数所属が見える状態を `editor.png` として保存します。
5. タイトルバー・ファイルパス・他のタブ・通知に個人情報や作品データがないか確認します。
6. 画像を置いてから、ルートREADMEの「画面例」に次の記述を追加します。

```markdown
![Character Relationship Chartの表示例](docs/images/preview.png)
![キャラクターのGUI編集](docs/images/editor.png)
```

`verification/` は開発時の記録用で公開対象外です。公開用画像だけをこのフォルダへ置いてください。
