# Character Relationship Chart — Web版

[English](README.md)

第4段階のWeb版です。配布ZIPをすべて展開し、JavaScript・FileReader・ResizeObserver・dialog・Blobのダウンロードに対応したデスクトップブラウザで `index.html` を開きます。同梱ファイルは一緒に置いてください。完成した配布物の利用にVS Code、Node.js、Webサーバー、インターネット接続は不要です。

起動時にはサンプルが表示されます。**設定を開く**でUTF-8の `.jsonc` または `.json` を1つ選択するか、画面へドロップしてください。対応する表示データを同時に選択・ドロップすることもできます。後から読み込む場合は **表示データを開く** を使います。表示データの名前は設定ファイルの完全な名前に `.view.json` を付けたものです。例: `cast.jsonc` と `cast.jsonc.view.json`。同じフォルダーのファイルを自動で読み取ることはありません。外部で編集した内容は同じファイルをもう一度選択して読み直します。

**編集**で人物・グループ・関係・全体設定を、VS Code版と同じGUIで編集できます。**反映**を押すとフォームの内容を相関図とページ内のJSONCへ適用します。編集画面を閉じて **設定をダウンロード** を押すと、反映済みの内容を、元の `.jsonc` / `.json` のファイル名を基本とするUTF-8のファイルとして取得できます。ブラウザが名前を調整したり、保存先を尋ねたりする場合があります。開始後はブラウザの保存先を確認してください。開始だけでは保存完了を判定できません。以後はダウンロードしたファイルを開いて利用します。未反映のフォーム入力をダウンロードへ暗黙に含めることはありません。

編集処理は共通コアを使用します。複数グループ所属、人物・グループのID変更時の参照追従、人物削除時の接続関係の削除、グループ削除時の所属解除は既存版と同じです。全体設定のタイトル・説明は追加・変更・空欄による削除ができます。変更対象外のコメント、改行、インデントは可能な範囲で保持します。項目の追加・削除では隣接範囲が整形される場合がありますが、ファイル全体をJSONへ変換し直すことはありません。`.json` 入力も拡張子を維持し、VS Code版と同じJSONC互換の内容を扱います。

検索、人物・関係のクリックによる詳細表示、ノードとキャンバスのドラッグ、拡大縮小、配置方式の変更、図だけ表示を利用できます。ノードのドラッグでは詳細を開かず、全エッジラベルはエッジ線より前面に表示します。人物IDを変更しても一時的なドラッグ位置と選択を引き継ぎます。配置変更は一時的で、画面を閉じる・再読込する・別の設定を開くと失われます。設定を開くと以前の選択・検索・配置をリセットし、対応する表示データがあればその配置を復元します。

不正なデータ、読込エラー、不正な編集では、直前の有効な図とフォーム入力を保持します。設定と表示データを同時に選んだ場合は、両方が有効なときだけ切り替えます。複数の設定、対応しない表示ファイル名、大きすぎる入力は拒否します。ダウンロードに失敗してもページ内の編集内容は残り、再試行できます。反映済みの編集や開いているフォームに入力がある場合、別設定への切替前に破棄確認を行います。ダウンロード後もブラウザの保存完了を判定できないため、この確認は残ります。編集がある状態でページを閉じる・再読込するときも警告を要求しますが、ブラウザによって表示されない場合があります。離れる前にダウンロードしてください。

元ファイルへの直接上書き、`.view.json` の保存・ダウンロード、SVGダウンロード、Web版のUndo/Redo、ファイル監視、外部変更の競合管理、localStorage・IndexedDBへの永続保存はありません。ダウンロードまではページのメモリー上だけで扱い、内容を外部へ送信しません。外部リソース・利用状況の収集・ネットワーク要求はなく、CSPでも接続を禁止します。ページの再読込では再びサンプルが開きます。

リポジトリのソースから作成する場合:

```sh
npm ci
npm run build:web
```

生成された `dist/web/index.html` を開いてください。`web/index.html` はビルド用テンプレートです。esbuildは開発時だけ使用します。実際の共通コア、`jsonc-parser`、共有UIとGUIエディターをまとめ、VS Codeアダプターは含めません。既存の拡張は `src/` と `media/` に維持しています。依存の版数は第3段階から変更していません。

配布物にはプロジェクトと `jsonc-parser` のMITライセンス、サンプルJSONCを同梱します。検証環境と未確認事項はリポジトリの `TESTING.md` を参照してください。
