# Character Relationship Chart — Webビューアー

[English](README.md)

第3段階の読取専用Web版です。配布ZIPをすべて展開し、JavaScript・FileReader・ResizeObserverに対応したデスクトップブラウザで `index.html` を開きます。同梱ファイルは一緒に置いてください。完成した配布物の利用にVS Code、Node.js、Webサーバー、インターネット接続は不要です。

起動時にはサンプルが表示されます。**設定を開く**でUTF-8の `.jsonc` または `.json` を1つ選択するか、画面へドロップしてください。対応する表示データを同時に選択・ドロップすることもできます。後から読み込む場合は **表示データを開く** を使います。表示データの名前は設定ファイルの完全な名前に `.view.json` を付けたものです。例: `cast.jsonc` と `cast.jsonc.view.json`。同じフォルダーのファイルを自動で読み取ることはありません。外部で編集した内容を読み直すときは同じファイルをもう一度選択します。

検索、人物・関係のクリックによる詳細表示、ノードとキャンバスのドラッグ、拡大縮小、配置方式の変更、図だけ表示を利用できます。ノードのドラッグでは詳細を開きません。全エッジラベルがエッジ線より前面に表示されます。配置の変更は一時的で、画面を閉じる・再読込する、別の設定やサンプルを開くと失われます。設定を開くと以前の選択・検索・配置をリセットし、対応する表示データがあればその配置を復元します。

不正なデータや読込エラーでは、直前の有効な図を残してエラーを表示します。設定と表示データを同時に選んだ場合は、両方が有効なときだけ切り替えます。複数の設定ファイル、対応しない表示ファイル名、大きすぎる入力は拒否します。データの上限はVS Code版と同じ共通コアで検証します。

編集、保存、SVGダウンロード、Undo、ファイル監視、競合管理、ブラウザへの保存はありません。内容はこの画面のメモリー上だけで扱い、外部へ送信しません。外部リソース・利用状況の収集・ネットワーク要求はなく、CSPでもネットワーク接続を禁止しています。ページを再読込すると再びサンプルが開きます。

リポジトリのソースから作成する場合:

```sh
npm ci
npm run build:web
```

生成された `dist/web/index.html` を開いてください。`web/index.html` はビルド用テンプレートです。esbuildは開発時だけ使用します。実際の共通コア、`jsonc-parser`、共有UIをまとめ、VS CodeアダプターとGUIエディターはWeb版に含めません。既存の拡張は `src/` と `media/` に維持しています。

配布物にはプロジェクトと `jsonc-parser` のMITライセンス、サンプルJSONCを同梱します。検証環境と未確認事項はリポジトリの `TESTING.md` を参照してください。
